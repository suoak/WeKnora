## 入口、网络和证书

目标外部 URL 为 `https://knowhub.ruijie.com.cn:8443/api/v1/mcp/personal`。先确认防火墙/交互设备是否允许复用 HTTP 入口所在机器及域名解析。优先通过已批准独立 TLS 边界代理或现有 Nginx 的独立监听终止 TLS；选择由实际拓扑决定。绝不顺带把整站切换 HTTPS。

正式证书候选受控位置为 `/etc/knowhub/tls/isolated-mcp/`（需运维确认）。私钥目录 0700、文件 0600，由受控证书流程安装；容器只读挂载，不写 Git、镜像、普通配置、聊天或日志。上线前再次核验 SAN、有效期、完整链、算法支持及证钥匹配。测试 CA 和测试私钥禁止用于生产，原生产证书不在本轮复制。边界设备终止 TLS 时证书留在该设备受控存储。

批准规则应为精确隔离出口/NAT 地址 → 指定 TLS 终止地址 TCP8443，默认拒绝其他来源。源 CIDR 尚未知，不提供可直接套用的宽网段规则。明确拒绝隔离区到 APP8080、80旧入口、其他 MCP、PG、Redis、对象存储及 IPv6/备用地址旁路；由网络管理员给出命中证据，并从隔离区实测。当前本地测试 ACL 仅允许环回，不是生产白名单。

域名必须在隔离区解析到获批 TLS 终止地址，SNI/SAN 为 `knowhub.ruijie.com.cn`，客户端校验完整链。优先复用现有解析；如确需变更 DNS，单独申请审批，禁止本任务自行变更。边界转发不得拓宽到任意 REST/URL。

## Nginx 与 Compose 变更包

测试模板为 [p1_nginx.conf.template](p1_nginx.conf.template)，含精确原始 URI、固定改写到 APP 的 `/internal/mcp/isolated/personal`、方法/Content-Type、1MiB、无重放/缓存/缓冲、速率/慢请求/并发及无正文日志配置。生产包必须重新渲染实际 upstream、批准 Host、证书路径与源 ACL，去掉过期证书负向测试端口 18443；不能照搬环回测试地址，也不能把外部8443直通旧内网 Go 路由。

若现有 Nginx 容器承载 TLS：保留原 80映射/配置，只增加经批准地址的 `8443:8443` 和证书/新增监听配置只读挂载。新增 Docker 端口映射通常需要重建前端容器，应评估短暂影响并安排维护窗口。独立代理可避免重建现有前端，但仍需网络与运维批准。APP8080、数据库、Redis不新增发布端口。

复用现有永久只读 PersonalServer 和原认证，隔离入口独立服务端路由仅承担严格协议与脱敏边界；旧内网 Go 路由保留原协议和正文契约。不依赖 `X-Environment`、客户端 denyTools 或隐藏工具。未来内网写工具使用独立处理逻辑，不能扩充该只读注册表。跨多个边界代理实例时，分别配置的并发预算总和必须小于现有 8 槽；测试单实例隔离全局上限为4。按实际 NAT用户数量调整速率，同时保留内网预算。

部署前离线验证 `nginx -t`、证书及 Compose 渲染，仅输出允许字段。日志/WAF/APM策略必须在接收正文前完成：不持久化请求体、查询串、认证、知识正文、任意客户端元数据和签名链接；保留受控状态/耗时/调用计数。测试模板关闭错误日志的载荷输出，生产监控应通过无正文元数据和独立健康探针补足。

## 审批后的执行顺序与验收

先批准变更窗口、最小镜像和回滚责任人，再安装证书/发布安全补丁与独立监听，验证旧80入口与内网MCP，最后仅放行获批隔离源。开放前确认 REST/文件默认拒绝和固定8工具。使用批准的专用合成资源运行协议、权限、上传拒绝、日志标记和业务副作用验收；不得对真实知识发送未经批准的负向写入载荷。

生产发布必须同时满足 [30项矩阵](P1_TEST_RESULTS.md) 中网络、外部日志、桶策略和生产制品待验证项，不以 P1 PASS 替代。保留无正文证据、源/镜像/配置摘要和已批准网络规则。

## 回滚

1. 关闭新隔离入口及其连接：撤销本次新增源放行或停用独立 TLS 代理，保留内网旧 HTTP 入口。
2. 恢复本次新增 Nginx/Compose 配置及原镜像。仅操作本次组件，不停现有数据库/Redis或整站；前端重建依维护窗口执行。独立入口完全撤下后才回滚应用安全补丁，避免仍暴露隔离流量。
3. 验证旧网站和既有 MCP 的同 Key/授权/只读检索，确认新8443不可达，检查无新业务写入。不改个人 Key，不回滚数据库，不删除知识或任务。

P1 已在专用容器演练停止隔离 Nginx、内网 HTTP 仍可用并恢复 TLS。生产边界设备撤规则和既有前端镜像切换仍为 NOT_RUN，须在批准窗口另行验收。
