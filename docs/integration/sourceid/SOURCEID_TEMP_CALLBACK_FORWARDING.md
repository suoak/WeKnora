# 临时 callback 转发方案

> 最新实现限定：cmd/sourceid-probe 的独立回调为 /probe/callback，配置校验拒绝旧 /api/v1/auth/oidc/callback。以下 A 复用旧审批地址的讨论不适用于当前实现。需 SID 审批独立 /probe/callback 地址，外层网关仅转发 /probe/start 与 /probe/callback，其他业务路由保持原状；没有外层入口时使用新测试端口/专用测试域名。当前未修改任何现有服务或 callback 登记。运行细节见 [Probe 实现](SOURCEID_PROTOCOL_PROBE.md)。

2026-10-13。仅用于单次只读协议诊断。以下为待审批方案，未修改 DNS、网关、现有 80/8080 服务、数据库或 SID callback 登记。

## 已知边界

SID 已审批 callback：http://knowhub.ruijie.com.cn/api/v1/auth/oidc/callback。

测试机 172.30.232.42；独立实例 127.0.0.1:18182。该 loopback 端口不能被远端网关直接访问。生产级 callback 架构本轮不建设；不使用 localhost/hosts 模拟。

现有业务 callback 会绑定用户并签发本地令牌，临时转发必须指向新建的只读诊断 callback，不能盲目指向当前业务 handler。只读诊断端口待部署时确定，下面以 <probe-loopback-port> 为占位符，不能当成已运行端点。

## A：复用已审批地址，经已有外层入口做短期转发

适用于 knowhub.ruijie.com.cn 已有可独立配置的外层网关，且可以在不改测试机现有 80/8080 服务的情况下路由。

1. 平台先确认该域名真实 DNS/入口节点与网关所有者；本轮未核实其实际承载，不假定入口就在测试机。
2. 在测试机新建专用临时转发器，使用新的 loopback 端口，转发到诊断进程。若网关不在同机，建立短期、受限的网关到测试机通道；不把 127.0.0.1 当成远端可达地址，不开放整个业务 app。
3. 外层网关仅对批准域名和准确 callback 路径设置临时规则，并限制到已确认的测试浏览器来源。浏览器 callback 来自员工浏览器，不能错误地仅放行 SID 后端 IP。共享 NAT 无法区分用户时，须明确影响范围和短测试窗口。
4. 诊断进程仅接受本次一笔有效 state/nonce 事务，拒绝其他请求。网关对非测试来源保留原路由，保证已有静态/API/业务流量不转移。
5. 保留外部 Host、协议及端口语义，兑换时 redirect_uri 必须与批准地址逐字一致；不把内部端口地址放入 authorize/token 的 redirect_uri。
6. 所有临时转发层禁用请求行、查询串、Referer/Cookie/Authorization/Location/正文日志和抓包。常规 Nginx error_log 也会附完整 URL，须阻断该输出；不能仅替换 access_log 格式。
7. callback 直接返回脱敏诊断完成页面，不跳转到业务登录 landing/result，不依赖或创建 KnowHub 业务登录 Cookie。
8. 测试后撤销精确规则、关闭短期通道和诊断进程，核对原域名行为及现有 80/8080 服务正常。

实际网关配置、浏览器来源、通道方式、窗口、回退命令尚未知。取得这些信息后提交精确配置差异和影响清单，经用户确认才执行；此文不构成正式域名路由变更授权。

## B：审批一个专用临时 callback（无外层网关时采用）

如果域名直接到达现有 80/8080 且没有独立外层路由，就无法在完全不改现有服务的同时接管该批准 URL。不要尝试停旧前端、抢占端口或改 hosts。

由 SID 审批一个临时测试 callback；在新端口/专用测试域名上部署短期转发器，仅暴露诊断 callback 和测试授权入口，限制测试浏览器来源。独立监听、转发器、防火墙变更也应先提交具体方案。HTTP/HTTPS、端口或 IP 地址是否可被 SID 接受须由 SID 确认，不能自行将示例地址作为批准地址。

该方案不复用或替换 80/8080；诊断完成即撤销登记或禁用入口。不得通过新入口开放后端统一登出。

## 放行前证据

- 正式 SID Metadata 和 client auth 已确认。
- 只读诊断代码及 Mock/云端验证通过，证明零绑定、零本地令牌、无秘密持久化。
- 精确回调路径、外部地址和 redirect_uri 一致，浏览器能到达测试入口；未发起真实授权前仅做无凭据可达性检查。

- 操作员自行输入 Secret/企业密码，不导出浏览器 Cookie 或 HAR。
