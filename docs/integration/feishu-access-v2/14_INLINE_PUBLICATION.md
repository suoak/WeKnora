# 一键导入与共享发布

本次将共享发布确认并入主操作。选择已有知识库、粘贴链接后，点击“一键导入”即可提交；共享目标在按钮上方说明发布给该知识库的现有读者。私人目标不附带共享发布请求。

旧批次的批准缺失状态提供“一键继续导入”，一次请求登记明确的发布意图并恢复原条目，不需要权限预检、填写理由、进入高级设置或另行重试。原批次、条目、知识及审计 ID 保留。

服务端仍要求明确的 `publish_to_readers: true`，并沿用知识库所有者或租户管理员的发布权限；普通写权限不足以代替发布权限。未传确认标志的旧客户端不会被隐式授权。网页导入与继续接口仍仅接受原有 JWT 会话，MCP 凭据不获得写权限。

批次确认与任务接收原子持久化，HTTP 202 前不读取飞书元数据或正文。后台领取后，按原个人身份解析用户提交的资源，将首次核验的资源版本批准与条目绑定原子提交。崩溃后重试、租约竞争、撤销批准均不得重新绑定其他版本。确认及批准最多有效 24 小时，不通过重试延期。

迁移 3042 仅添加两列；存量批次确认字段保持 NULL，不补写同意，不删除、移动或重建知识。带有确认或绑定状态的数据库拒绝有损降级；升级前完成停机备份及恢复校验，数据库恢复不作为自动回滚手段。

个人连接和应用配置在交接与实际创建 attempt 之间保持绑定。正文下载权限、个人隔离、来源停止门禁、旧版本与受保护知识、索引成功回执及原子发布均由原管线继续校验。此改动不批准未来版本，不恢复 paused/hold/revoked 来源，不扩大同步范围。

验证范围：真实 PostgreSQL 持久化、幂等与批准意图区分、有限重试、版本与撤销不重绑、过期租约和实时角色校验、原批次恢复、私人目标、连接切换防护；SQLite 升降级保留审计；实际 Vue/Chromium 一次提交十条链接、共享与私人目标、旧批次一次继续和移动端布局。最终执行结果记录在同目录 evidence 中，模拟接口验证不替代 Sheet/Bitable 的真实入库验收。
