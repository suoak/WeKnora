# 飞书导入界面精简验收

2026-10-26，开发分支 `feature/knowhub-feishu-access-v2`。只更新隔离测试站前端，不合并 main、不部署生产、不修改 PR #50。

## 交互和安全变化

- 删除普通导入界面的 HTTP 测试声明、发布范围长声明、不自动创建知识库声明；高级导入页面也不重复显示 HTTP 警告。不添加替代长说明。
- 保留连接状态、已有知识库、多行链接、一键导入、可选文档选择与简短入队反馈。当前 KB 内打开时自动使用当前目标；列表入口选择已有目标。
- `quickImportFeishu` 不再接受共享批准布尔参数，也不发送 `publish_to_readers`。目标是否共享不再构成用户已知情批准的依据。
- 历史页删除会隐式发送 `publish_to_readers:true` 的“一键继续导入”。缺少授权时显示简短错误，并保留“处理共享审批”入口和高级页既有显式审批操作。
- 未新增部门级自动共享策略，也未根据领导通知推定存在可审计授权。仍由现有后端验证用户、KB、资源版本及有效批准；缺少授权的条目可以进入持久队列，但不得发布。
- OAuth 跳转前保留链接、KB 草稿和含 query 的原页面地址；原有回调及页面恢复逻辑继续使用同一待办记录。
- HTTP 测试环境限制、到期、审计和服务器安全校验均保持；删除导入弹窗警告不代表站点变为 HTTPS。

后端保持 `b11a0b7f1d89cf8ec640bb4eb6c61322f1d47e37`。部署工具核对后端源码指纹相同、APP/worker2/DocReader/PostgreSQL/Redis 容器 ID 和后端环境不变，仅替换 frontend/entry/entry-preview 镜像，保留原 Compose 供前端恢复。同步停止锁、Cursor、真实业务数据不参与本次部署修改。

## 新反馈文档的真实诊断

用户追加链接匹配到 `test` → `test001` 的 11:52:38 批次，脱敏批次 ID `441b55cf85f1`、条目 `7de6370f39d3`。

- 快速接口返回 HTTP 202；已有当前版本共享批准绑定 `7fa8aba770b7`。
- 真实资源类型为 Docx。attempt `83203481cc0b` 在 11:52:54 记录 `export_permission_required`，未重试；manifest 大小为 0，无正式 Knowledge。
- 该条目在 11:53:35 转为失败。没有进入解析、Embedding 或索引阶段，不能当成 UI 一直未刷新。
- 历史页将“无法读取文档”和“缺少导出权限”分别显示，避免仅有笼统提示。
- 追加权限探针在发出飞书导出请求前发现当前访问凭据已到期，探针不自行续期，故未创建上游导出任务、未读取正文、未写入知识。访问凭据到期不等于整个授权失效，正常服务仍可能使用刷新凭据续期；也不能反推 11:52 的失败就是凭据到期。目前没有飞书具体拒绝码足以证明一定是文档所有者禁用导出。

只读不意味着禁止导入：当前实现无需编辑权限，但使用个人 OAuth 的导出接口获取正文，因此还要求相应读取/导出权限和目标发布授权。不能通过改用应用身份或直接抓取网页绕过禁止导出。
