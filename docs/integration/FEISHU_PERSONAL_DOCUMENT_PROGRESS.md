# 飞书个人文档开发进度

2026-10-18。OA测试环境已持续启用，当前运行镜像仍为5f988be51/832b6652a，不部署本轮飞书代码，不重做OA架构，不操作生产。

## 复用的已有成果

- 企业统一应用配置、系统管理员专用配置API、AES-GCM存储和脱敏读取。
- 独立个人OAuth授权、用户绑定、一次性state、用户Token刷新与解绑；不复用SID/OA凭据，也不回退到企业Token读取个人文档。
- 单链接解析、导出、导入指定可写知识库、导入记录、手动增量重同步、跨副本租约及失败保留旧知识。
- 飞书旧Wiki/Drive连接器和其限流/重试基础能力。

## 本轮继续开发的首个增量

- 新增JWT用户专用 `GET /api/v1/me/feishu/resources`，服务层再次检查当前用户与飞书授权。
- 云盘根目录/指定文件夹单页读取、opaque cursor分页；每次50条、响应2MiB上限，非法Token、重复cursor和异常响应拒绝。
- 仅返回选择文档所需的字段，不返回OpenID、owner标识或凭据；文档链接验证官方域及资源类型/标识一致性。
- 慢请求期间解绑或应用配置切换后，不返回旧身份列表；目录浏览不创建导入、空间或知识库记录。
- UI新增云盘浏览、文件夹导航、分页和文档选择，保留粘贴链接及现有导入入口；明确列表不代表全部共享文档。
- 选择操作只填充链接，真正写入仍由既有导入流程校验飞书读取权限和KnowHub知识库写权限。

API依据：[飞书官方文件夹清单文档](https://open.feishu.cn/document/server-docs/docs/drive-v1/folder/list)。此阶段不宣称可无遗漏枚举个人全部历史/共享文档，也不把源飞书ACL自动复制为KnowHub ACL。
