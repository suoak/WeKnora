## 删除修复的边界

按数据源、个人导入资源、attempt、文档的顺序加锁；核对同一租户、库、文档、单链接配置。
只允许尚未 enrollment、没有待执行/运行中同步或有效 claim、没有其他文档绑定的专用来源。
同一事务停用并软删除专用来源，再通过既有 personal generation fence 和文档 CAS 标记删除。
保留配置、游标、导入历史、原任务及失败信息。失败或 CAS 冲突回滚整个事务。
共享来源、跨租户来源、已 enrollment 的资源继续拒绝，不能套用此恢复工具。

`cmd/knowledge-delete-recover` 只接受一条原归档 Web 删除任务，且最后错误必须精确匹配本故障。
它重查发起人当前成员身份和删除权限，用同一个 repository 方法完成事务预演；预演全部回滚。
正式执行要求预演快照一致，随后只重试原任务一次，由正常 Worker 完成文件、分块和索引清理。
工具不会启动 Worker、重启服务、取消同步或清空队列。
