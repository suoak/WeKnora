# 飞书同步的提供方故障隔离

已签名的正常服务启用、自动控制器与独立同步队列共同生效时，飞书、Embedding 和后台图片模型的 HTTP 拒绝、连接失败、超时及有限重试耗尽，只使当前请求失败，不再把整个安装永久锁住。执行许可、来源权限、SSRF、并发与 RPM/TPM 检查继续执行；失败响应及不完整向量不能发布，已发送请求不退回额度。Embedding 的明确提供方失败进入原有文档失败记录和有限重试，其他文档继续。

旧版本留下的 Embedding HTTP 停止记录，只能由新控制器在正常服务签名有效、真实消费者和成员完整、网关指纹匹配时迁移。原始 HTTP 证据与最新审计事件、正常服务记录通过同一 Lua 操作比较；先写迁移审计，再移除匹配的旧记录并生成短期许可。历史审计、队列消息、游标、执行历史和知识不重写。

人工紧急停止、未知停止原因、错误或缺失证据、撤权、非正常服务模式、人工队列暂停及审计失败仍不自动恢复。旧的本地已关闭 Guard 不会重新打开。严格或事件恢复模式继续使用原行为。

验证需覆盖：403 后独立来源仍可执行，限流重试有上限且计费不退，不完整向量被拒绝，来源撤权不被归为普通文档失败，旧提供方停止正常迁移，以及人工停止、消费者缺失、签名/记录变化、错误网关和审计写入失败时保留停止。发布后通过正常页面的“立即同步”和真实定时任务验收；按钮成功、应用 healthy 或单次手动成功均不能替代完整验收。
